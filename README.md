# HouseholdAccountBook (가계부)

은행 거래내역과 신용카드 명세서를 한 데이터베이스(SQLite)에 모아, 중복을 빼고 월별 수입·지출을 보여 주는 프로그램입니다.
**데스크톱 앱**(tkinter)과 **웹페이지**(Flask)가 같은 DB를 사용합니다.

## 폴더 구조

```
05_HouseholdAccountBook/
├─ DataSource/                 ← 원본 자료 (Bank/, Card/ 아래 아무 하위 폴더나 가능)
└─ HouseholdAccountBook/       ← 이 프로그램
   ├─ data/household.db        ← 데이터베이스 (자동 생성, git 에 올리지 않음)
   ├─ hab/                     ← 핵심 로직 (파서, DB, 가져오기, 조회)
   │  └─ parsers/              ← 양식별 파서 (새 양식은 여기에 추가)
   ├─ web/index.html           ← 웹 화면
   ├─ desktop_app.py           ← 데스크톱 앱
   ├─ web_app.py               ← 웹 서버
   └─ import_all.py            ← DataSource 전체 일괄 입력
```

## 처음 실행

1. Python 3.10 이상 설치 (설치 시 "Add to PATH" 체크)
2. `install.bat` 실행 (필요 패키지 설치)
3. `import_all.bat` 실행 → DataSource 폴더 전체를 DB로 가져옴 (여러 번 실행해도 중복 없음)
   - 암호 걸린 PDF 명세서(IBK 등)까지 읽으려면 암호를 뒤에 붙여 실행: `import_all.bat 900101` (명령 프롬프트에서). 암호는 저장되지 않습니다.
4. `run_app.bat`(앱) 또는 `run_web.bat`(웹, http://localhost:5000) 실행

이후 새 자료는 앱/웹의 **데이터 입력** 버튼으로 넣으면 됩니다. 웹으로 올린 파일은 `DataSource/Bank` 또는 `DataSource/Card` 에 사본이 저장됩니다.

## 화면 기능

- **맨 위**: 선택한 달의 수입 / 지출 / 수입−지출 / 카드 사용액(사용일 기준, 참고용)
- **계좌별 잔액**: 각 통장의 최신 잔액(클릭하면 그 계좌만 보기)
- **월별 그래프**: 최근 12개월 수입·지출 (막대를 누르면 그 달로 이동)
- **거래 목록**: 날짜, 시간, 계좌/카드번호, 지출금액, 입금금액, 상대계좌번호, 상대계좌예금주명, 송금메세지, 거래구분, 이용가맹점, 할부(개월/남은 개월), 상세내역, 메모, 잔액
  - 보기: 통장 / 카드 / 전체
  - **내 계좌 간 이체 표시** 체크박스로 보유 계좌끼리 오간 거래를 보이거나 숨김 (합계에서는 항상 제외)
  - 통장 출금 중 **카드대금 결제** 금액을 클릭(앱은 더블클릭)하면 해당 명세서의 세부 사용내역 표시
  - 통장 거래·카드 상세내역 옆 **메모(직접 입력)** 칸에 원하는 내용을 기록 (웹: 칸 클릭, 앱: 더블클릭 / Enter 저장, Esc 취소). 파일을 다시 넣어도 메모는 유지됨
- **반복 거래**: 지난달과 계좌·금액·상세내역이 같은 거래에 '전달 동일' 표시, 반복 거래는 메모를 묶음 전체·이후 거래에 공유
  (사람 이름 이체는 자동 제외). 웹은 '반복' 칸의 ★/☆, 앱은 오른쪽 클릭으로 직접 지정·제외, 소스 화면에서 되돌리기
- **월 보고서 인쇄/PDF** 버튼: 선택한 달의 요약·월말 잔액(총합 포함)·통장 거래·카드 사용내역을 A4 가로로 인쇄하거나 'PDF로 저장'
- 계좌별 잔액 오른쪽 끝에 **잔액 총합**(마이너스 통장 포함) 표시
- **소스** 버튼: 보유 계좌번호·카드번호, 입력된 파일 목록, '내 계좌' 지정, 계좌 추가
  (본인 명의 상대계좌—예: 증권계좌—를 추가하면 그 계좌와의 이체도 지출/수입에서 빠집니다)

### 새 양식 추가 방법
`hab/parsers/` 에 `Parser` 를 상속한 클래스를 만들고 `detect()`(이 양식인지 판별)와 `parse()`(거래 목록 반환)를 구현한 뒤,
`hab/parsers/__init__.py` 의 `PARSERS` 목록에 넣으면 됩니다. 기존 `banks.py`, `cards.py` 가 예시입니다.

## 중복 처리 규칙

- 같은 파일(내용 동일)은 다시 넣으면 건너뜀
- 통장: 계좌 + 거래일시 + 출금 + 입금 + 거래후잔액이 같으면 같은 거래
- 카드: 카드 + 이용일 + 금액이 같으면 같은 거래 (명세서와 승인내역이 서로 겹쳐도 1건, 할부는 매달 명세서에 나와도 1건으로 저장하고 최신 회차로 갱신)
- 한 파일 안에서 같은 날 같은 금액이 2건이면 2건 모두 보존

## 내 계좌 간 이체 판단

1. 상대계좌번호가 '내 계좌'인 거래
2. 내 계좌 A의 출금과 내 계좌 B의 입금이 같은 금액이고 10분 이내(`config.json` 의 `transfer_window_sec` 로 조정)

## 설정 (선택)

`config.json` 을 만들면 기본값을 바꿀 수 있습니다.

```json
{ "db_path": "data/household.db", "datasource_dir": "../DataSource", "transfer_window_sec": 600, "web_port": 5000 }
```
